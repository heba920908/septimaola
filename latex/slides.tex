\begin{itemize}
  \item Séptima Ola nace en Ciudad de México como una fusión honesta entre reggae, ska y rocksteady, con letras orientadas a la unión y la conciencia social.
  \item Una banda que fusiona ritmos latinos con melodías contemporáneas para crear una experiencia sonora única

  \item Entre sus proyectos destacados se incluye ``Desde mi Ventana'' y ``Contraluz''.
\end{itemize}

\section{Rider técnico}
{\setbeamertemplate{background}{%
  \begin{tikzpicture}[remember picture,overlay]
    \node[anchor=center,opacity=0.22] at (current page.center)
      {\includegraphics[width=\paperwidth,height=\paperheight]{./assets/bkg_tecnico.png}};
  \end{tikzpicture}}
\begin{frame}[plain]{Resumen técnico}
\begin{itemize}
  \item \textbf{PA y mezcla reggae:} Sistema LR capaz de entregar bajos profundos y medios definidos. Consola con al menos 24 canales, 6 envíos auxiliares y compresores para voz principal y bajo.
  \item \textbf{Microfonía (7 músicos):} SM58 o KSM8 para voz líder, 2 micros dinámicos para coros/teclado, SM57 para guitarra, clip para saxofón, condensador de violín, kit de batería (bombo, tarola, OHs) y DI activas para bajo y teclados.
  \item \textbf{Monitores/sidefills:} 4 wedges independientes (voz líder, coros/teclado, sección rítmica, vientos) y, de ser posible, sidefill para percusiones y metales.
  \item \textbf{Backline:} Batería completa con bombo 22", tarola 14", 3 toms, platillos medium. Amplificador de bajo de 500W con caja 4x10 y ampli de guitarra 1x12 o 2x12. Percusión latina: congas, bongó, campanas y soporte.
  \item \textbf{Alimentación eléctrica:} 6 contactos independientes con tierra física para teclados, efectos de guitarra, pedalboards y cargadores inalámbricos.
  \item \textbf{Extras reggae/dub:} Envío auxiliar para efectos de delay/dub, preferentemente con pedal o rack a pie de sala, y lámparas de escenario cálidas para facilitar cambios instrumentales.
\end{itemize}
\end{frame}}
